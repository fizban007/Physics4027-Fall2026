Part I · Rules on a grid

Trapezoidal · Simpson

Starting from the definition

The Riemann sum with $N$ intervals of width $h = (b - a)/N$:

$$\int_a^b f(x)\,dx \approx \sum_{i=0}^{N-1} f(x_i)\,h$$

This converges, but the error shrinks only as $h$.

Why the error is $O(h)$

  • On one interval, the rectangle ignores the variation of $f$. By Taylor expansion, $f(x) - f(x_i) \approx f'(\xi)\,(x - x_i)$, so one interval contributes error $$\int_{x_i}^{x_{i+1}} \left[f(x) - f(x_i)\right] dx = \tfrac12 f'(\xi_i)\,h^2.$$
  • There are $N = (b - a)/h$ intervals. Summing $N$ terms of size $h^2$ costs one power of $h$: $$\varepsilon = \frac{h}{2}\sum_i f'(\xi_i)\,h \approx \frac{h}{2}\int_a^b f'\,dx = \frac{h}{2}\left[f(b) - f(a)\right].$$
  • Notation. $\varepsilon = O(h^p)$ means $|\varepsilon| \le C h^p$ as $h \to 0$, with $C$ independent of $h$. Halving $h$ divides the error by $2^p$; on a log-log plot against $N$, the slope is $-p$.
DERIVATION details. f(x) - f(x_i) = f'(xi(x)) (x - x_i) is the mean value theorem, exact, with xi(x) between x_i and x. Pulling f' out of the integral uses the integral mean value theorem: (x - x_i) is nonnegative on the interval, so int f'(xi(x)) (x - x_i) dx = f'(xi_i) int (x - x_i) dx = f'(xi_i) h^2/2 for some interior xi_i (f' continuous). The second step is the same Riemann-sum replacement as on the trapezoid slide: sum f'(xi_i) h -> int f' = f(b) - f(a), at relative cost O(h). Geometric picture if asked: each interval's error is roughly the triangle between the flat top and the curve, width h, height |f'| h, area f' h^2 / 2.

Trapezoidal rule

Replace $f$ on each interval by its linear interpolation, and integrate:

$$\int_a^b f(x)\,dx \approx \left[\tfrac12 f(x_0) + f(x_1) + \cdots + f(x_{N-1}) + \tfrac12 f(x_N)\right] h$$

Interior points are shared by two trapezoids and get full weight; the endpoints get half.

Trapezoidal rule: the error

With $N$ intervals of width $h = (b - a)/N$, the error of the trapezoidal rule is

$$\varepsilon = \frac{h^2}{12}\left[f'(a) - f'(b)\right] + O(h^4)$$
  • Sketch: expand $f$ around each interval's midpoint; the trapezoid overshoots the exact integral by $\tfrac{1}{12} f''(m)\,h^3$ per interval, and the $N$ per-interval errors add up to $O(h^2)$.
  • The error comes from the curvature: straight lines ($f'' = 0$) are integrated exactly.
BOARD DERIVATION. One interval, centered at m, width h. Expand: f(x) = f(m) + f'(m)(x-m) + (1/2) f''(m)(x-m)^2 + ... (1) Exact integral from m-h/2 to m+h/2: the f' term is odd about m and integrates to zero; the quadratic term gives (1/2) f'' * (h^3/12) = f'' h^3/24. So: f(m) h + f'' h^3/24. (2) Trapezoid: f(m +- h/2) = f(m) +- f'(m) h/2 + (1/2) f''(m) h^2/4; in the average the f' terms cancel: (h/2)[f(m-h/2) + f(m+h/2)] = f(m) h + f'' h^3/8. (3) Exact minus trapezoid: (1/24 - 1/8) f'' h^3 = -f'' h^3/12 per interval. (4) Sum over N intervals: -(h^2/12) sum of f''(m_i) h, and that sum is a Riemann sum for int_a^b f'' = f'(b) - f'(a), giving the slide's formula. The same midpoint symmetry kills the third-derivative terms on both sides, so the next correction is h^5 per interval, h^4 total: only even powers, which is the Euler-Maclaurin slide.

The Euler–Maclaurin formula

The trapezoidal error has an exact expansion, the Euler–Maclaurin formula:

$$\varepsilon = \sum_{k=1}^{\infty} \frac{B_{2k}}{(2k)!}\,h^{2k} \left[f^{(2k-1)}(a) - f^{(2k-1)}(b)\right]$$
  • $B_{2k}$ are the Bernoulli numbers ($B_2 = \tfrac16$ gives the $\tfrac{1}{12}$).
  • Only even powers of $h$ appear. Removing the $h^2$ term therefore improves the error to $h^4$, two orders at once.
The full Euler-Maclaurin proof (integration by parts against Bernoulli polynomials) is beyond lecture scope; quote it and cite Numerical Recipes 4.2 if pressed. What CAN be shown quickly: the h^2 coefficient from the previous slide, and the absence of odd powers by symmetry: on one interval, odd-order terms of the expansion around the midpoint integrate to zero and the trapezoid value is symmetric in a and b, so the error is even in h.

Simpson's rule

Simpson's rule

Interpolate a parabola through each pair of intervals and integrate it. With $N$ even:

$$\int_a^b f(x)\,dx \approx \frac{h}{3}\left[f(x_0) + 4f(x_1) + 2f(x_2) + \cdots + 4f(x_{N-1}) + f(x_N)\right]$$

The pattern $1, 4, 2, 4, \dots, 2, 4, 1$: each parabola spans two intervals and weights its midpoint by 4.

Simpson's rule: the error

  • The error is $$\varepsilon = \frac{h^4}{180}\left[f'''(a) - f'''(b)\right] + O(h^6),$$ two orders better than trapezoidal, for the same number of function evaluations.
  • A parabola guarantees exactness for quadratics. Simpson's rule is in fact exact for cubics as well.
  • Why? A cubic minus its interpolating parabola is odd about the midpoint of the pair; its integral vanishes by symmetry.

Symmetric rules gain an extra order for free.

DERIVATION of cubic exactness. On [x0, x2] with midpoint x1, write the cubic as c(x) = q(x) + alpha (x - x1)^3 with q the quadratic that interpolates c at the three nodes... cleaner: let d(x) = c(x) - p_2(x) where p_2 interpolates c at x0, x1, x2. d is a cubic vanishing at the three nodes, so d(x) = alpha (x - x0)(x - x1)(x - x2), which is odd about x1; its integral over [x0, x2] is zero. So int c = int p_2 = Simpson. The h^4/180 coefficient for one pair follows from the interpolation error with the quartic term; per-pair error is -(h^5/90) f''''(xi), and summing over N/2 pairs telescopes to the slide's boundary form (same move as the trapezoid).

Part II · Adaptive refinement

How many points are enough?

Refine until it stops changing

The right $N$ is usually not known in advance. Instead, keep doubling it, reusing the values already computed:

$$\begin{align} S_1 &= \tfrac12\left[f(a) + f(b)\right]h_1, & h_1 &= b - a \\ S_2 &= \tfrac12 S_1 + f\!\left(\tfrac{a+b}{2}\right)h_2, & h_2 &= \tfrac12 h_1 \\ S_3 &= \tfrac12 S_2 + \left[f\!\left(a + \tfrac{h_1}{4}\right) + f\!\left(a + \tfrac{3h_1}{4}\right)\right]h_3, & h_3 &= \tfrac12 h_2 \end{align}$$

Each level evaluates $f$ only at the new midpoints; no value is computed twice.

Estimating the error

  • The trapezoidal error is $\varepsilon \approx \tfrac{h^2}{12}[f'(a) - f'(b)]$, and the boundary term does not change under refinement: halving $h$ divides the error by 4.
  • So the difference between consecutive levels estimates the error: $$\varepsilon_n \approx \tfrac13\,(S_n - S_{n-1})$$
  • Refine until $|\varepsilon_n|$ (or $|\varepsilon_n / S_n|$) drops below your tolerance.
DERIVATION of the 1/3. Let I be the true value. S_{n-1} = I + e, S_n = I + e/4 (error divided by 4). Subtract: S_n - S_{n-1} = -3e/4, so e/4 (the error OF S_n) = -(S_n - S_{n-1})/3... sign aside, |error of S_n| = |S_n - S_{n-1}|/3. Same structure as a convergence test in root finding: the computable difference of successive approximations stands in for the uncomputable error.

Cancel the error instead

If $S_{n-1}$ carries error $e$ and $S_n$ carries $e/4$, a linear combination can cancel $e$ entirely:

$$S'_n = \frac{4 S_n - S_{n-1}}{3}$$

Writing $S'_n$ out in terms of the function values shows that it is exactly Simpson's rule on the finer grid.

  • Its error estimate: $\varepsilon_n \approx \tfrac{1}{15}(S'_n - S'_{n-1})$.
  • Strategy: run the doubling trapezoidal levels $S_1, S_2, \dots$, form $S'_n$ at each level, stop when the estimate is below tolerance.
DERIVATION that S' is Simpson: on one coarse interval with midpoint m, S_{n-1} = (h/1)[f(a)/2 + f(b)/2] (h = b-a) and S_n = (h/2)[f(a)/2 + f(m) + f(b)/2]. Then (4 S_n - S_{n-1})/3 = (h/6)[f(a) + 4 f(m) + f(b)] = Simpson on [a, b]. The 1/15: Simpson's error scales as h^4, so consecutive levels have errors e and e/16; S'_n - S'_{n-1} = -15/16 e, giving |error of S'_n| = |S'_n - S'_{n-1}|/15. This whole idea (combine two step sizes to cancel the leading error term) is Richardson extrapolation; iterating it is Romberg integration.

Implementation


template <typename F>
std::tuple<bool, double> adaptive_simpson(const F& f, double a, double b,
                                          double tol) {
  // repeat the doubling trapezoidal levels, form S' at each level,
  // stop when the error estimate drops below tol
}
  • Same conventions as the root finders: {converged, value}, a maximum refinement depth, false if the tolerance is never reached.
  • The tolerance discussion from root finding applies unchanged: absolute or relative, and there is a floor set by rounding.

Part III · Gauss quadrature

Choosing the nodes

Moving the nodes

  • Every rule so far has the shape $$\int_a^b f(x)\,dx \approx \sum_{i=0}^{n-1} w_i\,f(x_i),$$ with the $x_i$ fixed on an even grid. Rules of that family are called Newton–Cotes formulas.
  • Now let the $x_i$ move. That doubles the free parameters: $n$ weights and $n$ node positions, $2n$ in total.
  • A polynomial of degree $2n - 1$ has $2n$ coefficients. Chosen well, $n$ evaluations can integrate every such polynomial exactly.

With $n = 5$, five function values can integrate any degree-9 polynomial exactly.

Gauss–Legendre quadrature

  • On $[-1, 1]$: the nodes $x_i$ are the $n$ roots of the Legendre polynomial $P_n(x)$, and the weights are $$w_i = \frac{2}{(1 - x_i^2)\left[P'_n(x_i)\right]^2}.$$

  • The nodes come in $\pm$ pairs with equal weights, and none of them are endpoints. They cluster toward the endpoints, where interpolation error is largest.
  • In practice: tabulated, or computed once by Newton's method on $P_n(x) = 0$.

Any interval

Gauss–Legendre lives on $[-1, 1]$. For $[a, b]$, substitute $x = \tfrac12(b - a)\,t + \tfrac12(b + a)$:

$$\int_a^b f(x)\,dx = \frac{b - a}{2}\int_{-1}^1 f\big(x(t)\big)\,dt \approx \frac{b - a}{2} \sum_{i=0}^{n-1} w_i\, f\big(x(t_i)\big)$$

A linear change of variable and one overall factor.

Convergence of Gauss quadrature

The same test integral, $\int_0^2 x^4 \sinh^{-1}(x)\,dx$, cost measured in function evaluations:

  • With 12 evaluations the error is $4 \times 10^{-14}$; Simpson would need about $10^5$ intervals. The error falls geometrically with $n$, not as a power of $h$.

Why it is exact at degree $2n-1$

Take any polynomial $f$ of degree $\le 2n - 1$ and divide by $P_n$:

$$f(x) = P_n(x)\,q(x) + r(x), \qquad \deg q,\ \deg r \le n - 1$$
  • The $q$ piece integrates to zero: $P_n$ is orthogonal to every polynomial of lower degree, and $\int P_n q = 0$.
  • The rule never sees $q$: at the nodes, $P_n(x_i) = 0$, so $f(x_i) = r(x_i)$.
  • The $r$ piece is easy: $\deg r \le n - 1$, so $r$ is its own interpolation through the $n$ nodes, and the weights $w_i = \int_{-1}^1 \ell_i(x)\,dx$ integrate it exactly.

The rule never sees the part of $f$ that it would integrate to zero anyway.

DERIVATION, full chain. (1) Polynomial division gives f = P_n q + r with deg q, r <= n-1 (2n-1 = n + (n-1)). (2) Legendre orthogonality: int_{-1}^1 P_n P_m = 0 for m < n, and q is a combination of P_0..P_{n-1}, so int P_n q = 0. Hence int f = int r exactly. (3) At the nodes f(x_i) = r(x_i) since P_n(x_i) = 0. (4) r has degree <= n-1 and n values pin it down (Lecture 4 uniqueness!): r = sum r(x_i) l_i(x) with the Lagrange basis on the nodes. Integrate: int r = sum r(x_i) int l_i = sum w_i r(x_i) = sum w_i f(x_i). Chain: sum w_i f(x_i) = int r = int f, exact. The closed form of the slide's weight formula (2 / (1-x_i^2) P_n'(x_i)^2) equals int l_i via Legendre identities; quote it (Numerical Recipes 4.6) rather than derive. Note the weights are all positive, which keeps the rule numerically stable.

Drawbacks of Gauss quadrature

  • Non-smooth integrands. The derivation assumed $f$ is well approximated by a high-degree polynomial. A kink, a singularity ($1/\sqrt{x}$), or a discontinuity breaks the geometric convergence.
  • Oscillatory integrands. $\sin(1/x)$ near $0$ is not well approximated by any polynomial.
  • No cheap error estimate. Different $n$ share no nodes, so estimating the error requires a full recomputation.

Use Gauss quadrature for smooth integrands; use adaptive Simpson when $f$ is poorly understood or an error estimate is needed.
